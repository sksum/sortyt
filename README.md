# Sort YouTube Tabs by Duration

Minimal Manifest V3 Chrome extension. Click the toolbar button: all YouTube
watch tabs in the current window move to the front, sorted ascending by video
duration; every other tab keeps its relative order, after them.

## Install

1. `chrome://extensions` → enable **Developer mode**
2. **Load unpacked** → select this folder
3. Open some YouTube watch tabs (mixed with other tabs) and click the extension's toolbar icon

Live streams / unreadable durations sort last. Only `youtube.com/watch` URLs count (no Shorts). Current window only.
